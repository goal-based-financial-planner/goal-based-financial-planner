# Implementation Plan: Planner Page Layout Redesign

**Branch**: `016-layout-redesign` | **Date**: 2026-07-11 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/016-layout-redesign/spec.md`

## Summary

Replace the cramped 75/25 two-column layout with a full-width three-tab design (Goals | Investment Plan | Portfolio). A persistent stat strip replaces the two unequal summary boxes. GoalGrowthChart moves to its own Portfolio tab. Goals move from a narrow right sidebar to a 2-column grid in the Goals tab. No new dependencies, no domain or storage changes.

## Design Decisions

### Top-level tab structure
Three tabs at Planner level, managed by `useState<0|1|2>`:
- Tab 0 — Goals: GoalBox content (one-time + recurring sub-tabs), Add Goal button in header
- Tab 1 — Investment Plan: InvestmentSuggestionsBox (allocation plan + tracker sub-tabs)
- Tab 2 — Portfolio: GoalGrowthChart at full width

### Stat strip values
Computed in `Planner/index.tsx`:
```
totalRequired = round(sum over investmentBreakdownForAllGoals[*].investmentSuggestions[*].amount, by name)
totalInvesting = round(sum of plannerData.investmentLogs[*].monthlyAmount)
```
`targetAmount` already computed there.

### Goal grid
`GoalList` switches from `Box flex-column` to `Grid2 container`, each goal wrapped in `Grid size={{ xs: 12, md: 6 }}`. GoalCard padding increases from `px:1, py:1` to `px:2, py:2`.

### InvestmentTracker simplification
Remove:
1. Monthly Required / Monthly Investing stat boxes (moved to stat strip)
2. `<GoalGrowthChart … />` (moved to Portfolio tab)
Keep: comparison bars + SIP list.

### Tour updates
- `.target-box` step → update to `.stat-total-target` (add this class to the total target stat tile)
- `.financial-progress-box` step → remove (TermwiseProgressBox gone)
- `.financial-goals-box` step → update to `.goals-tab-panel`
- All other steps (`.add-goals-button`, `.investment-plan-box`, `.customize-button`, `.calendar-button`) unchanged

### Allocation Plan visual
Keep both charts at full width (pie % + donut ₹). Remove the `»»` arrow icon (cosmetic only). Relax breakpoints so donut chart appears on `md` instead of `lg`-only.
